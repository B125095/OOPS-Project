    What I’m building right now

    An ATM Simulator for my Object-Oriented Programming course. It imitates a real ATM in a safe, virtual setting: card and PIN login, balance, withdraw, deposit, PIN change and a mini statement, with every input validated.

    Balance and PIN stay private inside the classes, and savings and current accounts inherit from one base account, so the code shows OOP working on a familiar real-life system.
